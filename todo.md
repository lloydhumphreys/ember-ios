# To do

What Ember's web client does that this app doesn't yet.

- A rich-text composer (bold, lists, code). The composer sends plain text and mentions.
- Quote and Copy link in the message menu.
- Presence in the room lists.
- Inline video playback. Videos play full screen.
- Workspace, admin, bot and assistant settings.
- Join links and QR sign-in.
- Signing in with Memberful.
- First-run setup. The app hands it to Safari.
- Password reset on a server that asks for a Turnstile check. The app hands it to Safari.
- Custom room icons and branding. Rooms show a number sign or a lock.
- Push notifications. Ember's server sends Web Push only to a short list of browser push services, so a native app needs a change on the server first. [docs/push-notifications.md](docs/push-notifications.md) sets out the options.
- An iPad layout.
